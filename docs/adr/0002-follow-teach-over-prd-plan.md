# Follow the /teach method, not an upfront lesson plan

The original PRD generated a 6-lesson plan and a 6-term glossary at course creation, and wrote a learning record on every finished lesson. We deliberately follow Matt Pocock's /teach skill instead: there is no plan, only the next Lesson, chosen after each Finish from the Mission and the Learning records; Learning records are written only on evidence (not coverage); Glossary terms are added only once the Learner has shown they understand them. The zone of proximal development depends on this, and a fixed plan would go stale.

## Consequences

- The course page shows done Lessons plus one "Up next", not a full path.
- A Course ends when the Learner confirms the Mission's success picture is met, not after N Lessons.
- Quiz scores are stored as quiz attempts, separate from Learning records.
